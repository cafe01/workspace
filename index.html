Preview

Make a living folder usable.

Workspace is a local command application for inspecting, searching and opening source material. This is an unsigned preview for design partners, not a commercial launch.

Current release 0.1.0-preview.3. Release workspace-v0.1.0-preview.3 is recommended. Review its immutable release details or the public release catalog before installing.

Install Workspace

Choose your system, copy its command, and paste it into Terminal or PowerShell. The command downloads and runs the installer.

macOS

macOS 14+ on Apple Silicon. Paste into Terminal.

curl -fsSLo install-workspace.sh https://cafe01.github.io/workspace/install-workspace.sh && sh install-workspace.sh

Windows

Windows 10 or 11 x64. Paste into PowerShell.

Invoke-WebRequest https://cafe01.github.io/workspace/install-workspace.ps1 -OutFile install-workspace.ps1; if ($?) { powershell -NoProfile -ExecutionPolicy Bypass -File .\install-workspace.ps1 }

Ubuntu Linux

Ubuntu 22.04 or 24.04 x64 (glibc). Paste into Terminal.

curl -fsSLo install-workspace.sh https://cafe01.github.io/workspace/install-workspace.sh && sh install-workspace.sh

You can review the macOS/Linux installer or review the Windows installer before running it. The installer verifies the complete archive before activation and never asks for administrator access.

Prepare your Workspace

Placement is not readiness. Run workspace provision, then workspace provision --check. The application stores its host and prepared runtime in your user-owned application-data location; your folders and source files stay where they are.

Unsigned-preview recovery

Your operating system may warn before opening an unsigned preview. Keep normal system protections enabled. Verify the installer’s source and the release catalog, use the ordinary per-app “Open anyway” or “Run anyway” control only after that check, and contact support if an expected release is absent or verification fails.

For a failed install, rerun the downloaded installer after checking your network and disk space. It preserves the previously active host; do not delete Workspace folders or your workspaces to recover.
